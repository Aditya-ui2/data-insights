To verify your domain (digitvalues.vercel.app) in Google Search Console:

1. In Google Search Console, add a property for: "https://digitvalues.vercel.app".
2. Select the "HTML file" verification method.
3. Download the verification HTML file (e.g., "google1234567890abcdef.html").
4. Move or save this file directly inside this directory ("client/public/").
5. Push the changes to GitHub. Vercel will automatically build and deploy it.
6. Once deployed, click "Verify" in Google Search Console!
